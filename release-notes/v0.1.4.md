Fixes for Windows, and Quire no longer trips over leftovers from a crash or a restart.

## Fixed

- **No more blank terminal window when you upload a draft (Windows).** The part of Quire that reads and checks your drafts now runs without a console window.
- **Drafts no longer get stuck on "Checking" after a crash or a restart.** Quire could mistake an old note about its background process for one still running, and then never start it. It now knows when that note is out of date.
- **Stop Quire, Update Quire and Uninstall can no longer close another program.** After a restart, that same old note could point at an unrelated program (even your browser), which they would have stopped.
- **The installer's output is readable on Windows.** The list of pages at the end of "Building the app" no longer comes out as `Γöî Γùï`.
- **A failed automatic update no longer keeps Quire from opening (Windows).** Quire opens, and tries the update again next time.
- **`quire --stop` on macOS** only stops what runs on port 3000 when that is Quire.

## Privacy

- **Next.js usage reports are switched off.** Next.js, which Quire is built on, sends anonymous usage reports to Vercel by default when the app is built during an install or update. Quire's scripts now turn that off, so your PC sends nothing beyond the web searches and the daily update check.

## Updating

Use **Update Quire** from the Start menu (or run `quire-update`), or let Quire install it the next time it starts if automatic updates are on. Your drafts, reports and settings are kept.
